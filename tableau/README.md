# Tableau Public: homes vs incomes

A one-page Tableau Public dashboard with the project's Eurostat data: in Portugal, house prices rose 124% from
2015 to 2024 while median household income rose 65%, the widest gap of the eight economies compared
(price-to-income index 136, Netherlands 131, EU-27 106).

| Sheet | Data | Chart |
|---|---|---|
| Portugal: house prices vs household income | `data/prices_vs_income.csv` | two lines, 2015 = 100 |
| Price-to-income index, 2024 | `data/affordability.csv` | bars, Portugal in amber, sorted |
| Real house prices | `data/quarterly_prices.csv` | eight lines by quarter, Portugal highlighted |
| Dwellings permitted | `data/permits_pt.csv` | bars, 2005-2025 |

Two packaged workbooks, same design: `homes_vs_incomes.twbx` (English) and `casas_vs_rendimentos.twbx`
(Portuguese). Both are generated by `build_workbook.py` from the CSVs, which `prepare_data.py` writes from the
dbt exports in `../exports`.

```bash
python tableau/prepare_data.py     # exports/*.parquet -> tableau/data/*.csv
python tableau/build_workbook.py   # -> homes_vs_incomes.twbx (add --lang pt for the Portuguese version)
```

## Publish

1. Install **Tableau Public** (free, Mac and Windows): https://www.tableau.com/products/public/download
2. Open `homes_vs_incomes.twbx`. If Tableau asks where a data file is, point it to the file of the same name in
   `tableau/data/`.
3. Check each sheet and the dashboard (layout, number formats, axis titles; see the list below).
4. **File → Save to Tableau Public**. Name: *Homes vs incomes in Portugal*. Repeat with the Portuguese file.
5. On the published page: add the description, the link to guilhermerigonato.com, and pin it to the profile.

Checklist before saving: index axes start at 0 or 50, not at the data minimum; numbers without decimals on the
bar labels; "2015 = 100" in every index axis title; tooltips show the country and the value; the dashboard fits
1200 × 900.

The workbook XML was written by a script without Tableau to test it, so a sheet may open with a default colour
or sort. If a sheet does not open at all, build it by hand in a few minutes with the steps below.

## Build by hand (fallback, about 1 hour)

Connect: **Text file** → each CSV in `data/`. Then:

1. **Prices vs income**: `prices_vs_income`. Columns: `year` (discrete). Rows: SUM(`index_2015`). Colour:
   `series`. Filter: `geo` = PT. Mark: Line. Colours: house prices amber `#d97706`, income grey `#4b5563`.
2. **Price-to-income 2024**: `affordability`. Rows: `country_name`. Columns: SUM(`price_to_income_index`).
   Filter: `year` = 2024. Colour: `highlight` (Portugal amber, Other `#b8b8b8`). Sort descending. Add a reference
   line at 100.
3. **Real prices**: `quarterly_prices`. Columns: `quarter_start` (continuous quarter). Rows: SUM(`real_hpi`).
   Colour: `highlight`. Detail: `country_name`. Mark: Line.
4. **Permits**: `permits_pt`. Columns: `year`. Rows: SUM(`dwellings_permitted`). Mark: Bar.
5. **Dashboard** 1200 × 900: title text on top, the four sheets in a 2 × 2 grid, the source line at the bottom
   (texts are in `TEXT` in `build_workbook.py`, English and Portuguese).
